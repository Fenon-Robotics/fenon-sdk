# Codebase map

Every file, the module that owns it, what it is for, what it may import, and its status (`built`, `spec` = specified but not built). Update this file in the same pull request as any added, moved or removed file.

## Repository

| Path | Owner | Purpose | Status |
|---|---|---|---|
| `pyproject.toml` | packaging | Package metadata, dependencies (aiortc and av included, for live mode), tool configuration | built |
| `MANIFEST.in` | packaging | Source distribution contents: `prune tests` (setuptools would add top-level `tests/test*.py`); the wheel holds only `src/fenon` | built |
| `uv.lock` | packaging | Locked development environment, generated by `uv lock` | built |
| `.python-version` | packaging | Default interpreter for local development (3.13) | built |
| `README.md` | docs | User-facing quickstart: recorded mode (the default), waiting or not, outputs and their 24 h expiry, errors; live "coming soon" | built |
| `CONTRIBUTING.md` | docs | Repository rules, setup and checks | built |
| `.gitignore`, `.gitattributes` | repo | Ignored files; contract files and live test clips kept byte-exact | built |
| `.github/workflows/ci.yml` | CI | Lint, format, types, comments and codegen on 3.13; tests on 3.11–3.14 (Ubuntu) and 3.13 (Windows); tests with the lowest allowed dependencies on 3.11 | built |
| `scripts/sync_contracts.py` | codegen | Pins one fenon-api contract version: copies its `contracts/` into `docs/contracts/fenon-api/<version>/`, writes `SOURCE.md` (branch, commit, uncommitted changes, SHA-256 per file), then regenerates | built |
| `scripts/generate_types.py` | codegen | Generates the types and contract hashes from the pinned contract; finds model contracts from its `x-model-contracts` and `x-model-data-schemas`; `--check` for CI | built |
| `scripts/check_comment_rules.py` | repo rules | Fails on any `#` comment, and on any docstring but the module's, in `src/`, `scripts/`, `tests/` (generated files included) | built |
