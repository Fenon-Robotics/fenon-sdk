# Codebase map

Every file, the module that owns it, what it is for, what it may import, and its status (`built`, `spec` = specified but not built). Update this file in the same pull request as any added, moved or removed file.

## Repository

| Path | Owner | Purpose | Status |
|---|---|---|---|
| `pyproject.toml` | packaging | Package metadata, dependencies, tool configuration | built |
| `uv.lock` | packaging | Locked development environment, generated by `uv lock` | built |
| `.python-version` | packaging | Default interpreter for local development (3.13) | built |
| `README.md` | docs | User-facing quickstart | built |
| `CONTRIBUTING.md` | docs | Repository rules, setup and checks | built |
| `.gitignore`, `.gitattributes` | repo | Ignored files; contract files kept byte-exact | built |
| `.github/workflows/ci.yml` | CI | Lint, format, types, comments and codegen on 3.13; tests on 3.11–3.14 (Ubuntu) and 3.13 (Windows); tests with the lowest allowed dependencies on 3.11 | built |
| `scripts/generate_types.py` | codegen | Generates types and the contract hash from `docs/`; `--check` for CI | built |
| `scripts/check_no_comments.py` | repo rules | Fails on any `#` comment in `src/`, `scripts/`, `tests/` | built |
| `scripts/dev_api.py` | dev tools | Local simulation of every v1 endpoint for development (`--first-cut` answers `501` except `GET /v1/models`); never packaged | built |
