# Fenon Python SDK

The Python package for the Fenon SDK, maintained by Fenon Robotics.

This is the initial development release. It provides package version information;
client APIs are not available yet.

## Install

```sh
pip install fenon
```

## Check the version

```python
import fenon
print(fenon.__version__)
```

You can also run `python -m fenon`.

Source repository: https://github.com/Fenon-Robotics/fenon-sdk
